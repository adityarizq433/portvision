## Findings (numbered, priority by tier)

### Hard Gate HIGH

1. [R-39] Labels without htmlFor/id across operational forms. Devices/Index.tsx:93,99,106,116; Devices/Show.tsx:201,218; Locations/Index.tsx:74,78,82,105,109; Users/Index.tsx:78,82,86,90,113,117,121,125; Settings/Index.tsx:80,91,131. Screen readers cannot associate label to input. Reason: visible text is not a programmatic label.
2. [R-39] No cursor pointer system. No cursor-pointer in resources/js except Login.tsx:125. Buttons/links/selects rely on browser default. Reason: interactive affordance is not declared.
3. [R-25] Contrast risk on small muted text. app.css:18 #9CA3AF (text-xmuted) on white ~2.8:1 fails AA (needs 4.5:1). Used for subtitles, empty states, de-emphasized data. Reason: small grey text below WCAG AA.
4. [R-25] white/60 11px subtitle over dark photo. GuestLayout.tsx:20-21 subtitle over .pv-guest gradient fails AA for small text. Reason: opacity text over image has no guaranteed contrast.
5. [R-27] Users empty state missing. Users/Index.tsx:143-197 renders bare table when users is empty. Other pages have empty states. Reason: no view for zero operators.
6. [R-27] Error states swallowed. Dashboard.tsx:104 catch ignores errors; Devices/Show.tsx:55 same; SwitchVisualizer.tsx:57-58 only console.error; Topology/Index.tsx:203 only console.error. Reason: failures leave stale data with no user feedback.
7. [R-32] Keyboard gaps. Dropdown.tsx:41 Trigger is div onClick with no role/button/keyboard handling; SwitchVisualizer.tsx:127-137,172-182 focus not styled (only selected ring); topbar buttons in AuthenticatedLayout.tsx:192,211,237,253,268 have hover only, no focus-visible ring; Users/Locations edit controls are opacity-0 group-hover. Reason: not all interactive elements are operable and visible by keyboard.
8. [R-39] Broken label association. ResetPassword.tsx:71 htmlFor=password_confirmation has no matching input id (75-84). Reason: label points to nothing.
9. [R-39] ForgotPassword has no label at all. TextInput id=email with no label or aria-label. Reason: email field is unlabeled.
10. [R-03] Users table overflow risk. Users/Index.tsx:143 table has no overflow-x-auto wrapper (Dashboard, Devices do). Reason: table can force horizontal overflow on mobile.
11. [R-26] Pagination dead link. Devices/Index.tsx:202 href falls back to '#' with cursor-not-allowed when link.url is null. Reason: disabled control ships as a fake link instead of span.
12. [R-26] Dropped data. SwitchVisualizer.tsx:20 otherPorts is computed but never rendered (non-physical ports silently dropped). Reason: data fetched but invisible with no notice.
13. [R-32/R-39] Modal without dialog title. Modal.tsx:62-66 DialogPanel has no Dialog.Title/Description, so no aria-labelledby. Reason: dialog announcement may be missing.
14. [R-39] Console-only error. SwitchVisualizer toggle shows no spinner while isUpdating (238-249) and no error on failure. Reason: action fails silently.
